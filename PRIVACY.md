# Privacy Statement — Waktu Sholat Leeds

_Last updated: 11 June 2026_

**Waktu Sholat Leeds** is a free, open-source Windows desktop application that displays daily prayer times for Leeds, UK.

## Personal information we collect

**None.** This application does not collect, store, transmit, or share any personal information. There are no user accounts, no analytics, no telemetry, no advertising, and no tracking of any kind.

## How the application works

- Prayer times are read from a **local CSV file** bundled with the application. No data leaves your computer during normal use.
- All settings (such as language preference) are stored **locally on your own computer**.

## Network access

The application accesses the internet in exactly one case: when you manually click **"Check Update"**, it queries the public GitHub API (`api.github.com`) to compare version numbers and, with your explicit confirmation, downloads the installer from GitHub. This request contains no personal data beyond what any standard web request exposes (such as your IP address, which is handled by GitHub under the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement)). The application never contacts any other server.

## Third parties

We do not share any data with third parties, because we do not collect any data.
